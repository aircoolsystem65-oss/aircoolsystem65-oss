# Image guide (replace photos any time)

Save your photo as JPG, 800x600 (4:3) recommended, under 300 KB, with the SAME file name in the SAME folder. Nothing else needs to change.
Any size works: the website crops every photo to 4:3 automatically, so it fits mobile, tablet and laptop. Keep the main subject in the centre of the photo.
